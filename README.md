🛠️ How It Works
1️⃣ Login Process

User enters username and password

JavaScript checks credentials

If correct:

Login state is saved in localStorage

User redirected to lan.html

If incorrect:

Shows error alert

2️⃣ Landing Page Protection

When lan.html loads:

It checks localStorage

If user is NOT logged in → Redirects to login page

3️⃣ Logout Process

Removes login data from localStorage

Redirects back to login page
